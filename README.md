# Additional-PURGE-M-Visualization

## Additional Visualization for PURGE-M (Figure 4)

To improve the intuition behind **PURGE-M**, we provide the following supplementary visualization illustrating representative examples of the four data partitions (**YN**, **NY**, **YY**, and **NN**). The figure explains the retain/forget assignments and the purpose of each partition, providing an intuitive illustration of the PURGE-M data construction process.

**Figure.** Representative examples of the four PURGE-M partitions. **YN** (retain) contains the target object without the contextual cue, **NY** (forget) contains only the contextual cue, while **YY** and **NN** are reserved for evaluation because they do not provide useful object–context disentanglement signals..
